# REQ-006: 模型管理与扩展性

## 来源
用户要求规划好项目以便后续模型的增加，当前 model.json 有 48 个模型，9 个分类。

## 实现细节

### 功能描述
确保系统架构支持模型库的持续增长，新增模型流程简单高效。

### 新增模型流程
1. 在 model.json 中添加新模型条目（按现有数据结构）
2. 上传 GLB 模型文件和缩略图到 CDN
3. 添加模型多语言翻译到 `locales/{lang}/models.json`
4. 运行 `npm run generate` 重新生成静态页面
5. 部署更新后的静态文件

### 新增分类流程
1. 在 model.json 中使用新的 `meta.category` 值
2. 在翻译文件中添加分类名称翻译
3. 运行生成脚本，自动产出新分类页面
4. 更新导航菜单（模板中动态读取分类列表）

### 模型数据验证
- 生成脚本包含数据校验：必填字段检查、URL 格式验证
- 新增模型前可运行 `npm run validate` 检查数据完整性

### SEO 运营支持
- 每个模型详情页支持自定义 SEO 字段（可在模型数据中扩展）
- 支持为模型添加长描述/文章内容（用于 SEO 内容营销）
- 自动更新 sitemap.xml
- 分类页面支持自定义 SEO 描述文案

### 涉及模块
- `model.json` — 模型数据源
- `scripts/validate.js` — 数据校验脚本
- `scripts/generate-pages.js` — 页面生成脚本

### 边界条件
- model.json 数据结构向后兼容（新增字段可选，不影响旧模型）
- 生成脚本在模型数量增长到数百个时仍保持合理的构建速度
- CDN 资源不可用时页面仍可正常展示（fallback 图片）
