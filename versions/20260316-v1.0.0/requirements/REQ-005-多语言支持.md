# REQ-005: 多语言支持 (i18n)

## 来源
用户要求支持多语言网站。

## 实现细节

### 功能描述
网站支持多语言，初期支持英文（默认）和中文。

### 静态页面多语言
- URL 路径前缀区分语言：`/` (英文), `/zh/` (中文)
- 每种语言生成完整的独立页面集
- HTML lang 属性正确设置
- Hreflang 标签互相指向对应语言版本
- 翻译数据存储在 `locales/{lang}.json`

### Vue 应用多语言
- 使用 `vue-i18n` 插件
- 语言切换组件
- 翻译文件与静态页面共用 `locales/` 目录
- 编辑器 UI 文案多语言

### 模型数据多语言
- model.json 中的 `meta.title` 和 `meta.tags` 需要翻译
- 翻译数据存储在 `locales/{lang}/models.json`
- 生成脚本根据语言选择对应翻译

### 涉及模块
- `locales/` — 翻译文件目录
- `scripts/generate-pages.js` — 生成脚本多语言支持
- `src/` — Vue 应用 i18n 配置

### 边界条件
- 翻译缺失时 fallback 到英文
- 新增语言时只需添加翻译文件和更新生成脚本配置
- 用户浏览器语言自动检测和重定向
