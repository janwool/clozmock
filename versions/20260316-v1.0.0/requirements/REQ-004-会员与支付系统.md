# REQ-004: 会员与支付系统

## 来源
用户要求支持会员体系，采用"免费 + Pro 订阅 + 单次付费下载"的混合模式。使用 Firebase Auth 做认证，Lemon Squeezy 做支付。

## 实现细节

### 功能描述
构建完整的会员体系，包括用户认证、订阅管理、单次购买、权限控制。

### 会员等级

| 功能 | Free | Pro（订阅） | 单次购买 |
|------|------|-------------|----------|
| 浏览所有模型 | ✅ | ✅ | ✅ |
| 使用 Free 模型 | ✅ | ✅ | ✅ |
| 使用 Pro 模型 | ❌ | ✅ | 单个解锁 |
| 前端快速导出 | ✅（有水印/低分辨率） | ✅（无水印/高分辨率） | ✅（已购买的模型） |
| 后端高质量渲染 | ❌ | ✅ | ✅（已购买的模型） |
| 动画导出 | ❌ | ✅ | ✅ |
| 每日下载限制 | 3 次 | 无限 | 购买的模型无限 |

### 用户认证（Firebase Auth）
- Email/密码注册登录
- Google OAuth 登录
- 密码重置
- 邮箱验证
- 用户 Profile 管理

### 订阅方案（Lemon Squeezy）
- **Pro Monthly**：月付
- **Pro Yearly**：年付（折扣）
- 自动续费、取消、升降级
- Webhook 通知更新 Firestore 中的用户订阅状态

### 单次购买（Lemon Squeezy）
- 用户可购买单个 Pro 模型的使用权
- 购买后永久解锁该模型
- Webhook 通知更新 Firestore 中的用户已购列表

### Firestore 数据结构
```
users/{userId}
├── email: string
├── displayName: string
├── subscription: {
│     plan: "free" | "pro",
│     status: "active" | "cancelled" | "expired",
│     lemonSqueezyCustomerId: string,
│     lemonSqueezySubscriptionId: string,
│     currentPeriodEnd: timestamp
│   }
├── purchases: [  // 单次购买的模型
│     { modelId: string, purchasedAt: timestamp }
│   ]
├── downloads: {
│     today: number,
│     lastResetDate: date
│   }
└── createdAt: timestamp
```

### 涉及模块
- Firebase Auth 配置
- `functions/` — Cloud Functions（Webhook 处理、权限验证）
- `src/dashboard/` — 用户仪表盘（Vue 应用）
- 静态页面的登录/注册组件（可用 Firebase UI 嵌入）

### 数据流
1. 用户注册/登录 → Firebase Auth → 创建 Firestore 用户文档
2. 用户订阅 → Lemon Squeezy Checkout → Webhook → Cloud Function → 更新 Firestore
3. 用户使用模型 → 前端检查权限 → Cloud Function 验证 → 允许/拒绝操作
4. 用户单次购买 → Lemon Squeezy → Webhook → 记录到 purchases 数组

### 边界条件
- 订阅到期后降级为 Free，已下载的内容不受影响
- 单次购买的模型永久有效，不受订阅状态影响
- 并发下载的频率限制
- Webhook 处理失败的重试机制
- 用户删除账户时的数据清理
