# REQ-001: 项目架构与技术栈

## 来源
用户明确指定的技术选型和架构决策。

## 实现细节

### 整体架构
采用**双层架构**：
1. **静态 SEO 层**：Node.js 脚本 + 模板引擎（EJS）读取 model.json，生成静态 HTML 页面（首页、分类页、模型详情页、定价页等）
2. **交互应用层**：Vue 3 + Vite 构建 3D 编辑器等交互密集型功能

### 技术栈
| 层级 | 技术 |
|------|------|
| SEO 静态页面 | Node.js + EJS 模板引擎 |
| 交互应用 | Vue 3 + Vite + TypeScript |
| 3D 渲染 | Three.js (前端预览) |
| 后端服务 | Firebase (Auth / Firestore / Cloud Functions / Storage) |
| 支付系统 | Lemon Squeezy (订阅 + 单次付费) |
| 样式方案 | Tailwind CSS |
| 多语言 | i18n 方案（静态页面多语言路径，Vue 应用 vue-i18n）|
| CDN/部署 | Firebase Hosting / Cloudflare |

### 项目目录结构（预期）
```
mockdown/
├── model.json                    # 模型数据源
├── scripts/                      # 构建脚本
│   └── generate-pages.js         # 静态页面生成器
├── templates/                    # EJS 模板
│   ├── layouts/                  # 布局模板
│   ├── pages/                    # 页面模板
│   └── partials/                 # 组件片段
├── src/                          # Vue 应用源码
│   ├── editor/                   # 3D 编辑器
│   ├── dashboard/                # 用户仪表盘
│   └── shared/                   # 共享组件
├── public/                       # 静态资源
├── dist/                         # 构建输出
│   ├── *.html                    # 生成的静态页面
│   └── editor/                   # Vue 应用构建产物
├── functions/                    # Firebase Cloud Functions
├── locales/                      # 多语言翻译文件
├── firebase.json                 # Firebase 配置
└── package.json
```

### 数据流
- model.json → Node.js 脚本 → EJS 模板 → 静态 HTML（SEO 页面）
- 用户点击"开始设计" → 进入 Vue 3D 编辑器应用
- 用户操作 → Firebase Cloud Functions → 高质量渲染/导出

### 涉及模块
- 构建系统、模板系统、Vue 应用、Firebase 配置、部署流程

### 边界条件
- 静态页面与 Vue 应用之间通过 URL 参数传递模型 ID
- 静态页面需支持增量生成（新增模型时只生成新页面）
- Vue 应用以独立入口挂载，不影响静态页面加载性能
