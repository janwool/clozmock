# REQ-003: 3D 编辑器（Vue 应用）

## 来源
核心交互功能。用户选择模型后进入 3D 编辑器，上传设计、自定义颜色/背景、预览效果、导出成品。采用混合模式：前端 Three.js 实时预览 + 后端高质量渲染导出。

## 实现细节

### 功能描述
基于 Vue 3 + Three.js 构建的 3D Mockup 编辑器，作为独立 Vue 应用运行。

### 入口方式
- 从模型详情页点击"开始设计"按钮
- URL 格式：`/editor/?model={model-id}`
- 编辑器通过 URL 参数获取模型 ID，从 model.json（或 API）加载模型配置

### 核心功能

#### 1. 3D 模型加载与展示
- 根据 model.json 中的配置加载 GLB 模型
- 应用 `camera` 配置设置初始视角
- 应用 `scene` 配置设置场景尺寸和位置
- 应用 `controls.distance` 设置缩放范围
- 支持鼠标/触摸旋转、缩放

#### 2. 设计图上传与贴图
- 用户上传设计图（PNG/JPG/SVG）
- 根据 `designs` 配置将设计贴到模型指定区域
- 显示 `designs[].guide` 指导图辅助用户定位
- 支持设计图的缩放、旋转、位置调整
- 支持多设计区域（部分模型有多个 `designs` 条目）

#### 3. 颜色自定义
- 根据 `object.elements[].mesh` 配置，提供颜色拾取器
- 支持修改模型各部件颜色（如 T 恤主体色、领口色等）
- 实时预览颜色变化

#### 4. 背景设置
- 纯色背景选择
- 渐变背景
- 透明背景
- 预设背景图片

#### 5. 动画预览
- 根据 model.json 中的动画资源（BounceDown, SpinCycle 等）
- 用户可选择动画效果预览
- 支持动画导出（视频格式）

#### 6. 导出/下载
- **前端快速导出**：截取 Canvas 当前画面为 PNG（免费用户）
- **后端高质量渲染**：调用 Cloud Functions 进行高分辨率渲染（Pro 功能）
- 支持多种尺寸和格式
- 下载前检查用户权限（Free/Pro/单次购买）

### 涉及模块
- `src/editor/` — 编辑器 Vue 应用
- `src/editor/components/` — Three.js 画布、工具栏、属性面板
- `src/editor/composables/` — Three.js 场景管理、模型加载
- `src/editor/stores/` — 编辑器状态管理（Pinia）

### 数据流
1. URL 参数 model-id → 加载模型配置
2. 用户上传设计图 → 存入 Firebase Storage → 贴到 3D 模型
3. 用户调整参数 → 实时更新 Three.js 场景
4. 用户点击导出 → 前端截图或后端渲染 → 下载文件

### 边界条件
- GLB 模型文件较大（几 MB），需显示加载进度
- WebGL 不支持的设备需提供降级方案
- 移动端需适配触摸交互
- 编辑器状态需支持自动保存（未登录用户存 localStorage，登录用户存 Firestore）
